# Security policy

## Supported versions

Only the latest minor release of each package receives security fixes.

## Reporting a vulnerability

Report it privately through **Security → Report a vulnerability** in this
repository. Do not open a public issue.

- You get an answer within 5 business days.
- A confirmed issue gets a fix or a mitigation plan within 30 days.
- You are credited in the advisory unless you ask otherwise.

OpenChasqui reads API contracts and writes collections. Reports about secrets
leaking into emitted files, writes outside the output folder, or unsafe parsing
of documents are especially welcome.
